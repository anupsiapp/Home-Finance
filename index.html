Google Apps Script Backend URL Integration

Provide the deployed Web App URL from your Google Apps Script editor. This binds your web application interface directly with your private Google Spreadsheet database for secure, real-time data persistence.

Deployment & Setup Reference

  1. Create a fresh Google Spreadsheet (sheets.new).
  2. Navigate to Extensions > Apps Script from the top menu bar.
  3. Create two script files: Setup.gs and Code.gs using the source files in our project folder.
  4. Run the initialSetup function in Setup.gs once to automatically format and configure all database sheets.
  5. Click Deploy > New deployment:
    • Type: Web App
    • Execute as: Me (your-account@gmail.com)
    • Who has access: Anyone (necessary for cross-origin browser fetch access)
  6. Copy the generated Web app URL, paste it into the field above, and click Save & Connect.
